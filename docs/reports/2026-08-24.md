## Built today

**Five run-30 fixes** — durable reach hops (css/xpath fallbacks, first-row-of-
list), screen-scoped dedup renames (~91 drops recovered), fillable-locate for
type/select, search-box echo-trap exception, 60s worker step watchdog +
validation run timeout 5 min → 1 min.

**The parallel pipeline** (docs/specs/test-writer/spec-parallel-pipeline.md,
§§1–4b all implemented + gated: typecheck, lint, 1204 tests):
journey writes ×4 (repairs ride along), plan/fill batches ×4, fact
transcription ×4 pages, batch verification ×3 sharded contexts, and the
**shared authenticated session** — one seed login exports browser storageState
to Redis (short TTL); parallel validation runs start pre-authenticated, so
authenticated validation went from 1-at-a-time to 3-wide with zero extra
credential submissions. Net: 2.5 h → ~40 min per run.

**The endpoint babysitting is dead** — scripts/llm-answerer.ts answers each
inbox prompt with a one-shot `claude -p` on **sonnet** (fresh process per
prompt: nothing to /compact, ~5× cheaper than the default model, concurrency 4,
env-overridable).

**Monitoring grew teeth** — the 2-min heartbeat now also greps testwriter and
worker logs for failure signatures (sign-in failures, seed misses, gateway
failures, unhandled errors) and raises HEALTH ALERT lines — the miss that let
run 34's sign-in failure go unseen cannot repeat silently.

## Bugs found and fixed today

1. **`__name` shim missing in the fact-verifier's contexts** (run 34's killer):
   tsx wraps named functions used inside page.evaluate; without the shim the
   ENGINE's assert_text threw ReferenceError in-page and read as "text not
   found" — sign-in "failed" and all 285 facts died. The worker and crawler
   carried the shim; the verifier did not. Fixed + sign-in now retries 3×.
2. **BullMQ zombie re-delivery** (twice: morning + post-reboot): a cancelled/
   killed job's Bull entry re-runs on container start and blocks the queue.
   Cleaned by hand both times; the durable fix (pipeline refuses terminal-row
   jobs) is on the engine backlog.
3. Run-30 decline-audit fixes (the five above) — ~27 wrongly-declined tests
   recovered.
