  (healed-not-learned) / FAIL / FALSE-PASS verdicts per expectation, fleet-wide
  negative controls (no green run may carry AssertionHealedOntoDifferentElement

- Spec: docs/specs/bench/spec-changing-sites.md (calibrated expectations

## Engine findings (the bench's deliverable)

1. **Phantom heals — FIXED.** The worker marked a step healed the moment a
   strategy *located* an element; the click/type was never re-executed
   (stress site: a 20-second-late widget "healed" with no effect). Fix: a
   successful non-assertion heal now re-executes the step and only counts
   when the retried action passes (src/workers/worker.ts). Proven live: the
   same seed that failed as a phantom now waits, re-clicks, and verifies.
2. **Delta name-fidelity exemption (open, bench stays red on it).**
   `verify the "Sign in" button is visible` PASSES after the button is renamed
   to "Log in" when resolution comes from the delta path — the worker's
   refuse-wrong-name gate deliberately exempts delta. A visibility assert of a
   renamed control should fail. (react-spa, FALSE-PASS row — intentional.)
3. **Delta memory not updated after a heal (open).** A delta-scoped assertion
   following a healed action errors AssertionNoAction — the heal path never
   feeds the delta capture. Honest failure, wrong reason. (stress.)
4. **Volatile-DOM interactions (open).** A list that re-renders in chunks
   detaches nodes mid-action; clear/type/click against it lose the race and
   the run fails. The stress site exists to measure exactly this. (stress.)

Positive proofs the same runs delivered: the engine **failed honestly** on a
changed assertion text (all three heal strategies refused, twice) and on a
removed feature; the checkout flow **resisted a decoy** lookalike; a renamed
button was **adapted to at resolution time** (fresh L5 re-pick by intent) and,
separately, **genuinely healed** via ResolveAndRetry with the re-executed
click verified; cosmetic id/class churn is invisible to the role-shaped cache.

## Bench infrastructure lessons (all fixed today)

- **Haiku wraps JSON in markdown fences** — the gateway's strict parse read
  fenced answers as empty, the inbox cached the poison, and every retry
  replayed it (317/2779 cache entries affected; killed the first jquery run
  wholesale). The answerer now strips fences; cache sanitized.
- Mid-loop token expiry (15-min JWTs) and loopback connect flakes under
  parallel load — one authedFetch with 401-reauth + retries everywhere.
- PowerShell 5.1 `Get-Content` mojibake'd UTF-8 site files during a bulk
  rewrite (em-dashes became `â€”`, corrupting assertion texts) — reversed
  byte-exactly with node; bulk text edits go through node now.
- A `.hidden` vs `.modal-scrim` CSS specificity bug in MY site left an
  invisible full-viewport overlay swallowing every click — the engine
  correctly refused to click through it for three runs straight while I
  blamed CDNs. The engine was right; the site was wrong.
